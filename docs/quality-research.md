# Исследование цели Pearson ≥ 0.8 и SSIM ≥ 0.8

**Новый этап завершён:** [полные результаты, PDF, изображения и код](../deliverables/quality_research/v2/README.md).
На test из 32 четвёрок сеть + уточнение общей фазы дали 0.67111/0.60637,
на выбранной пользовательской четвёрке — 0.59732/0.46088 с 3000 шагами.
Порог 0.8 не достигнут. Контроль с четырьмя отдельными ДОЭ даёт около 0.990/0.951,
но не соответствует исходному ТЗ. Далее сохранён журнал первого этапа.

Цель пользователя — оба показателя одновременно. Исходные физические условия,
PNG-квантование, 4 входа, 1 фазовый ДОЭ и протокол метрик сохраняются.
Ниже — промежуточные эксперименты, **не заявление о достижении 0.8**.

## Проверенные источники

- [Neural Holography, Peng et al., SIGGRAPH Asia 2020](https://github.com/computational-imaging/neural-holography):
  README и algorithms.py прочитаны. Подходы включают GS, SGD, HoloNet, U-Net,
  camera-in-the-loop и дифференцируемую оптику. Их пример использует angular
  spectrum и обучаемый масштаб амплитуды; автоматически переносить численные
  оценки на нашу одно-FFT четырёхплоскостную задачу нельзя.
- [Tensor Holography V1/V2, Shi et al.](https://github.com/liangs111/tensor_holography):
  README прочитан. Возможные направления — обучение phase-only синтезу и
  представление комплексного поля. Их постановка и кодировщики отличаются от
  нашего ДОЭ 128×128. Код и веса из этих проектов не копировались.

## Первый контролируемый эксперимент

Взяты первые 4 **validation**-четвёрки текстур, до просмотра новых результатов.
Использованы дообученные веса `deliverables/texture_finetuned/best.pt`.
Оптимизируется сама входная фаза, а не параметры сети. Это диагностический
итеративный расчёт для входных изображений, **не ускоренная нейросеть**.
Начальные метрики: Pearson **0.40725**, SSIM **0.24378**.

| Loss для 600 шагов Adam | Pearson после | SSIM после |
|---|---:|---:|
| Существующий physics loss | 0.53670 | 0.34401 |
| 0.5×ошибка Pearson + 0.5×ошибка SSIM + 0.05×MSE | **0.55028** | **0.45044** |

LR=0.05 с cosine decay, CPU, одинаковая начальная фаза и входы. Новый loss
использует straight-through 8-битное квантование и ту же нормировку каждого
модуля по его максимуму. Метрики таблицы вычислены отдельной существующей
функцией `phase_metrics`, включая реальное квантование фазы и PNG-амплитуды.
История каждого прогона сохранена в `deliverables/quality_research`.

SSIM-loss проверен против `skimage` на точность и конечными разностями по градиенту;
фазовое квантование сверено с существующим PNG-кодировщиком. Новые тесты прошли.

## Вывод и дальнейшая работа

Согласование loss с метриками помогает, но **эти два эксперимента не достигли
0.8 и не доказывают математическую невозможность цели**. Нужны проверки
инициализации фазы, других оптимизаторов и глубины сети. Настройка выполняется
по validation; тестовая выборка и выбранная четвёрка не используются для
выбора параметров этих экспериментов.

Нельзя выдавать за достижение цели оценки после фильтрации реконструкций,
обрезки неудобных областей, замены PNG входов или изменения SSIM. Более
сложный итеративный метод нужно измерять отдельно от одного forward pass сети.

Воспроизведение:

```bash
python scripts/probe_quality.py --objective perceptual --steps 600 --count 4 \
  --lr 0.05 --output NEW_RESULT.json
python scripts/probe_quality.py --objective physics --steps 600 --count 4 \
  --lr 0.05 --output ANOTHER_RESULT.json
```
