# Нейросетевой синтез четырёхплоскостного фазового ДОЭ

Четыре изображения 128×128 → **один фазовый ДОЭ 128×128** (PNG, 8 бит, оттенки серого):
проход нейросети и короткая доводка фазы через ту же физическую модель. При восстановлении методом дифракции Френеля (одно БПФ) изображение *i* фокусируется
на расстоянии 24,1 / 25,3 / 26,5 / 27,7 мм; λ = 532 нм, пиксел ПВМС 10 мкм.

**Сдаваемое решение — модель [`unrolled/`](unrolled/README.md)**: физически информированная развёрнутая
сеть на 8 стадий, веса `unrolled/weights/doe_net.pt`. Подробности — в [отчёте](unrolled/REPORT.md).

## Сборка и запуск в Docker

```bash
docker build -t doe-nn .
```

Входная папка: каждая подпапка — комплект из **4 PNG 128×128** (8 бит, оттенки серого). Порядок
изображений определяется **сортировкой имён файлов** (естественной: 1, 2, …, 10) и соответствует
расстояниям 24,1 → 25,3 → 26,5 → 27,7 мм. Один комплект можно положить и прямо в папку, без подпапок.

```
input/
  set_01/  1.png  2.png  3.png  4.png
  set_02/  ...
```

```bash
docker run --rm -v "$PWD/input:/data/input:ro" -v "$PWD/output:/data/output" doe-nn
```

В Windows PowerShell — `-v "${PWD}/input:/data/input:ro" -v "${PWD}/output:/data/output"`.

Результат для каждого комплекта — папка `output/<комплект>/`:

| файл | содержание |
|---|---|
| `doe.png` | **фазовый ДОЭ** 128×128, 8 бит, grayscale; 0 ↔ −π, 255 ↔ +π |
| `recon_1.png … recon_4.png` | модули полей, восстановленных из `doe.png` (самоконтроль) |
| `metrics.csv`, `metrics.json`, `preview.png` | КК и ИСС по плоскостям, сводная картинка |
| `inputs.json` | какие файлы каким расстояниям сопоставлены |

Плюс общий `output/summary.csv`: КК, ИСС и время синтеза по каждому комплекту.

Сеть не требует интернета и GPU: всё работает на CPU. Без подключённой папки (`docker run --rm doe-nn`)
контейнер обработает встроенные примеры.

**Метод по умолчанию:** один проход нейросети (8 стадий) плюс 50 итераций доводки фазы градиентом через
ту же модель Френеля (цель 0,35·(1−КК) + 0,65·(1−ИСС), со штрафом за «горячую точку»).

**Скорость (CPU, 4 потока):** ~0,7 с на комплект плюс ~1,5 с на запуск Python и загрузку модели.
Чистая нейросеть без доводки (`--refine 0`) — ~0,22 с на комплект.

**Параметры** (дописываются после имени образа):

| параметр | что делает |
|---|---|
| `--refine 50` | по умолчанию: 50 итераций доводки после сети; `--refine 0` — чистая нейросеть (~0,22 с), `--refine 200` — выше качество (~1,8 с) |
| `--refine-ssim-weight 0.65` | вес ИСС в цели доводки: 0,5 — баланс, 1 — только ИСС |
| `--alpha fast` | по умолчанию: один проход сети при α = 0,5; если найдена «горячая точка» (бывает на разреженных объектах), второй проход при α = 0 |
| `--alpha auto` | 5 вариантов α за один батч и выбор лучшего |
| `--no-extras` | сохранять только `doe.png` |

Пример: `docker run --rm -v "$PWD/input:/data/input:ro" -v "$PWD/output:/data/output" doe-nn --refine 0`.

**Соглашения физики** (если ДОЭ восстанавливается внешним кодом):

K = FFT2[exp(jφ) · exp(jπ(u²+v²)/λz)], прямое БПФ, координаты u = (m − 64)·Δu (центр массива — индекс 64), модуль после fftshift.

Это совпадает с независимой реализацией из присланных `expert_runs`: корреляция полей 0,99999999998.

**Зависимости:** `requirements.txt` (torch 2.9.1, numpy, Pillow, scikit-image, matplotlib). В образе ставится
CPU-сборка PyTorch. Без Docker:

```bash
pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python unrolled/predict.py --input input --output output
```

## Физическая модель

| Параметр | Значение |
|---|---|
| Размер | 128×128 |
| Длина волны λ | 532 нм |
| Входной шаг Δu=Δv | 10 мкм |
| Расстояния z | 24.1, 25.3, 26.5, 27.7 мм |
| Освещение | равномерное, амплитуда 1 |
| ДОЭ | H(u,v)=exp(iφ(u,v)), φ∈[−π,π] |

Используется формула из задания с дискретизационным множителем Δu²:

```text
U_z(x,y) = exp(ikz)/(i λ z) · exp[iπ(x²+y²)/(λz)]
           · Δu² · FFT{exp(iφ(u,v)) · exp[iπ(u²+v²)/(λz)]},  k=2π/λ.
```

Начало координат находится в центре массива. FFT центрированное. При FFT с
`norm='ortho'` восстанавливающий множитель равен `N Δu²/(iλz) · exp(ikz)`.
Никакой подмены одно-FFT модели на angular spectrum или свёртку нет.

**Сетка восстановления зависит от расстояния**:
`Δx_z=Δy_z=λz/(NΔu)`, то есть примерно
`10.0166, 10.5153, 11.0141, 11.5128 мкм`. Каждый входной объект трактуется на
своей соответствующей выходной сетке. Это не четыре изображения с одним и тем же
физическим шагом. В отчёте сохранён шаг для каждой плоскости.

Для устойчивого обучения оператор нормирован до унитарного: удалён только
однородный комплексный множитель каждой плоскости. При экспорте полный физический
множитель возвращается. Это не меняет форму модуля, Pearson и масштабированных PNG.

## Нейросетевой метод и обучение

1. Четыре входные амплитуды нормируются до единичного RMS: энергия равномерного
   фазового ДОЭ фиксирована. Градации серого интерпретируются как **амплитуда**, как
   требуется при сравнении с модулями в задании, а не как интенсивность.
2. Детерминированные случайные фазы в плоскостях объектов и обратные операторы
   Френеля дают начальное поле на ДОЭ. В тестовом режиме используются те же правила.
3. Каждый слой сети вычисляет четыре поля, накладывает ограничение на амплитуду,
   переносит их обратно и объединяет с обучаемыми весами. Обучаемое смешивание
   и общая небольшая CNN корректируют фазу. Модуль поля на ДОЭ остаётся единичным.
4. Число слоёв фиксировано. При инференсе выполняется один проход сети;
   **шагов Adam, поиска лучшей фазы и дообучения на тестовом изображении нет**.
   Каждый слой содержит прямые и обратные FFT: это физически информированная
   развёрнутая сеть, а не обещание «синтеза без дифракционных расчётов».
5. Loss состоит из MSE амплитуд с единичным RMS, многомасштабной ошибки и ошибки
   корреляции. Используются Adam, ограничение градиента и cosine learning rate.
   Голограммы-эталоны для обучения не требуются.

Проверочные данные — цифры, диски, прямоугольники, кольца и линии с варьируемой
геометрией и сглаживанием. Генератор и seed входят в поставку; PNG, manifest и
SHA256 позволяют воспроизвести набор. Три split имеют разные seed. Checkpoint
выбирается **только** по validation loss; отдельный test split используется для
финальной оценки. Обучение не гарантирует идеального восстановления четырёх
независимых объектов одним фазовым экраном: остаются спекл, межплоскостные помехи
и ограничения числа степеней свободы.

## Метрики и честное сравнение

- Фаза сначала округляется в 8 бит, PNG читается обратно. Реконструкции считаются
  из этой фазы — потеря качества квантования включена в оценку.
- Сохраняется `|U|`, не `|U|²`. Для PNG каждая плоскость делится на собственный
  максимум и округляется до 8 бит. Нет подгонки gain по target, вычитания фона,
  фильтрации или изменения размера. Исходные физические модули сохранены в `.npy`.
- Pearson вычисляется по центрированным пикселям; для постоянного изображения
  он математически не определён и записывается как `null`.
- SSIM: `skimage.metrics.structural_similarity`, окно 7×7, `data_range=1` после
  деления фактических PNG на 255; используется стандартная локальная версия SSIM.
- Сравниваются обученная сеть, такая же сеть до обучения и GS с малым/большим
  числом шагов. Все используют одинаковую физику, входы и квантование.
- Время измеряется после прогрева с синхронизацией CUDA и не включает загрузку
  файлов и метрики. В benchmark указано **batched seconds per quartet**, не latency
  одиночного запроса. Сбор данных и обучение в время инференса не входят.
- Превосходство по скорости или качеству не предполагается заранее: результаты
  конкретного измерения находятся в `benchmark.json` и `docs/validation.md`.

## Проверки и структура

```text
doe/optics.py       — физика, центрированные FFT и сопряжённый оператор
doe/model.py        — нейросеть, loss, классический GS
doe/data.py         — строгий ввод PNG и воспроизводимый набор
doe/engine.py       — обучение, выбор checkpoint, оценка, инференс

tests/             — независимая квадратура Френеля, adjoint, мощность,
                     finite differences, CNN-градиенты, PNG и метрики

scripts/           — генерация notebook и архива для экспертов

```

Оптический оператор сравнивается с прямой суммой интеграла дифракции **без FFT**
на малой сетке. Проверяются сохранение физической мощности с учётом выходного
шага, сопряжённость, градиент конечными разностями, границы фазы, строгий формат
PNG, повторное восстановление сохранённого ДОЭ и метрики известных случаев.

Обновление notebook после изменения кода: `python scripts/build_notebook.py`.
