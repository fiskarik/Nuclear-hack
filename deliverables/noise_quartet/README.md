# ДОЭ для выбранной четвёрки текстур

Это результат **до** дообучения. Сравнение с новой моделью и новые изображения:
[texture_finetuned](../texture_finetuned/README.md).

Входы: [Cracks 1, Gabor 1, Perlin 1, Voronoi 1](../../examples/noise_quartet/README.md),
в этом порядке. Использована готовая `deliverables/best.pt`, без переобучения и
без шагов оптимизатора во время инференса. Расчёт выполнен на CPU.

| Плоскость | Изображение | Pearson | SSIM |
|---:|---|---:|---:|
| 24.1 мм | Cracks 1 | 0.17021 | 0.10950 |
| 25.3 мм | Gabor 1 | 0.45041 | 0.39057 |
| 26.5 мм | Perlin 1 | 0.10769 | 0.05535 |
| 27.7 мм | Voronoi 1 | 0.42188 | 0.23688 |
| **Среднее** | | **0.28755** | **0.19807** |

Качество невысокое, заметен спекл. Сеть обучалась на процедурных геометрических
объектах; этот прогон не доказывает хорошее обобщение на текстуры. Изображения
выбраны заранее, не по лучшим достигнутым метрикам.

- `doe_phase.png`: ДОЭ, 128×128, PNG/L/8 бит, 0→−π и 255→+π.
- `reconstruction_1.png` … `reconstruction_4.png`: модули восстановленных полей,
  рассчитанные из сохранённого PNG ДОЭ, каждый масштабирован по своему максимуму.
- `target_1.png` … `target_4.png`: реальные входы этого прогона после grayscale-преобразования.
- `metrics.json` и `metrics.csv`: показатели по фактическим PNG, параметры и SHA256.
- `comparison.png` и `phase_preview.png`: визуализация результата.
- `.npy`: квантованная фаза в радианах, немасштабированные модули и комплексные поля.

Применяются те же физические параметры и протокол метрик, что описаны в основном
[README](../../README.md). Запуск на Kaggle и эксперимент на физическом ПВМС не
проводились в рамках этого прогона.
