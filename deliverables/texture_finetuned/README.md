## Измеренные результаты

| Набор | Pearson до | После | SSIM до | После |
|---|---:|---:|---:|---:|
| Test: 32 четвёрки из двух отложенных семейств | 0.55026 | **0.57364** | 0.39950 | **0.41853** |
| Выбранные Cracks/Gabor/Perlin/Voronoi | 0.28755 | **0.31135** | 0.19807 | **0.21861** |

Рост есть, но восстановление всё ещё шумное. GS за 80 шагов на том же test дал
Pearson 0.65675 и SSIM 0.49291 — качественнее, но медленнее. Сеть даёт около
41.7 мс на четвёрку в пакетном CPU-измерении, GS80 — около 203.1 мс.

Реальное дообучение исходного checkpoint: 30 эпох, лучший validation checkpoint
на эпохе 24. Validation physics loss: **0.329082 → 0.316214**. Время — 468.3 с,
устройство CPU, batch=4, Adam lr=0.001, seed=42. Оптимизатор начинал с новой истории.

Использован загруженный ZIP с 262 изображениями: 140 train, 28 validation,
28 test и 66 в резерве. Cracks/Gabor/Perlin/Voronoi полностью исключены из обучения
и выбора checkpoint. Подготовлено 256/32/32 четвёрки. Test использует повторно
28 исходных текстур, а не 128 независимых исходников.

Полный набор из 700 по ссылке OpenGameArt не скачивался из-за сетевой политики.
TensorFlow README прочитан как справочный материал: данные CIFAR-10 не использованы.
ResearchGate недоступен; диагностика chirp выполнена независимо по формулам модели.
Код сохраняет модуль поля и рассчитывает реконструкции из фактического 8-битного
ДОЭ. Фильтрация и подгонка gain по target не применялись.

Проверки: 11 тестов pytest. Все 6 исполняемых ячеек нового режима дообучения
в Kaggle notebook прошли локально с короткой конфигурацией. Полное обучение и
финальная оценка выполнены отдельно на CPU. Удалённый Kaggle-запуск не выполнялся.

Для инференса замените checkpoint в `doe predict` на
`deliverables/texture_finetuned/best.pt`. Подробная процедура:
[docs/texture-finetuning.md](../../docs/texture-finetuning.md).
