# Материалы решения

Последняя версия: **[дообучение на текстурах](texture_finetuned/README.md)**,
с PDF-отчётом, сравнением до/после, новыми весами и полным отдельным архивом.

Базовый `submission.zip` содержит код, сгенерированные наборы данных, checkpoint,
историю обучения, независимую тестовую оценку, проверенный локально notebook и
изображения. `best.pt`, JSON-отчёты и каталог `result` вынесены отдельно для
быстрого использования и просмотра на GitHub.

`noise_quartet` содержит отдельный расчёт на четырёх выбранных текстурах из
пользовательского архива. Их входы и оригиналы — в `examples/noise_quartet`.
Этот расчёт также включён в обновлённый полный `submission.zip`.

`result/doe_phase.png` — фазовый ДОЭ 128×128, PNG/L/8 бит. Значение 0 соответствует
−π, 255 — +π. `reconstruction_1.png` … `reconstruction_4.png` — амплитудные
реконструкции из этого сохранённого ДОЭ. `target_1.png` … `target_4.png` — входы
демонстрации. Метрики — в `result/metrics.json` и CSV.

Данные процедурные: это не отсутствующие в задании объектные изображения
организаторов. На 32 независимых четвёрках сеть дала средние Pearson 0.59643,
SSIM 0.09554. Качество умеренное; GS за 80 шагов в этом измерении качественнее.
Подробности: [отчёт проверки](../docs/validation.md).

Удалённый запуск в Kaggle и эксперимент на физическом ПВМС не выполнялись.
Notebook можно импортировать в Kaggle вручную; для автоматической отправки
требуется настроенный Kaggle API-доступ.
