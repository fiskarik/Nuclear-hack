# Исследовательские прогоны

JSON содержит параметры и измерения, NPZ — фазы и исходные targets, если они
сохранялись. Основная выборка здесь — первые 4 validation-четвёрки; файл
target_specific_wavefront использует только одну. Это исследовательский набор,
не независимая тестовая оценка.

`validation_independent_planes_600` — контроль с **четырьмя разными ДОЭ**.
Он не соответствует ТЗ одного общего ДОЭ. Его высокие оценки не означают
выполнения порога 0.8. `camera_*` меняет физическую сетку камеры; эти результаты
не являются улучшением модели при прежней дискретизации.

`robust_from_expert` и `softpeak_from_expert` используют фазу из
`validation_neural_3000` и затем ещё 1800 шагов. Времена в их JSON относятся
только к продолжению. Target-specific fitting изменяет веса под один вход
и не измеряет обобщение сети.
