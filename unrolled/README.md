# Нейросетевой синтез многоплоскостных фазовых ДОЭ

Решение задачи «Разработка нейросетевого метода синтеза дифракционных оптических
элементов» (НИЯУ МИФИ, лаборатория «Фотоника и информационная оптика», каф. № 37).

По 4 объектным изображениям 128×128 нейросеть за **один прямой проход** (~0,1 с на CPU)
рассчитывает фазовый ДОЭ 128×128, который при восстановлении методом дифракции
Френеля (одно БПФ) фокусирует изображение *i* на расстоянии *z_i*:

| параметр | значение |
|---|---|
| длина волны | 532 нм |
| пиксел ПВМС | 10 мкм |
| размер ДОЭ / изображений | 128×128 |
| расстояния | 24,1; 25,3; 26,5; 27,7 мм |
| ДОЭ | фазовый, −π…π → 0…255 (8 бит PNG) |

Подробные результаты, графики и сравнение с итерационными методами — в **[REPORT.md](REPORT.md)**.

Кратко:
- финальная сеть (`weights/doe_net.pt`) обучена ~3 ч на Kaggle GPU T4;
- на отложенных текстурах при α = 0,5 даёт КК 0,50 / ИСС 0,32 — на уровне ГС-200, но в 2 раза быстрее;
- с доводкой 100 итераций — 0,49 / 0,41;
- на четвёрке Cracks1/Gabor1/Perlin1/Voronoi1 — 0,427 / 0,268.

Потолок прямой оптимизации фазы для 4 плоскостей — 0,52 / 0,47 на текстурах и
0,70 / 0,65 на цифрах. Поэтому цель 0,85 / 0,85 в этой постановке физически
недостижима (раздел 5 отчёта).

## Быстрый старт

Все команды выполняются из папки `unrolled/`.

```bash
cd unrolled
pip install -r requirements.txt
python synthesize.py obj1.png obj2.png obj3.png obj4.png --out results/my_run
```

или для папки с `object_1.png … object_4.png`:

```bash
python synthesize.py --input-dir examples/textures_a --out results/textures_a
```

В папке `--out` появятся:

| файл | содержание |
|---|---|
| `doe.png` | фазовый ДОЭ 128×128, 8 бит, 1 канал; 0 ↔ −π, 255 ↔ +π |
| `recon_1.png … recon_4.png` | модули полей, восстановленных **из сохранённого 8-битного `doe.png`** прямым расчётом дифракции Френеля |
| `metrics.csv`, `metrics.json` | КК Пирсона и ИСС (SSIM) для каждой пары «исходное ↔ восстановленное», время синтеза |
| `preview.png` | сводная картинка |

Полезные параметры `synthesize.py`:

* `--alpha auto|0…1` — компромисс между метриками (см. ниже): `0` — максимум КК Пирсона,
  `1` — максимум ИСС (тёмный фон). По умолчанию `auto`: сеть за один батч-проход считает
  ДОЭ при α = 0; 0,25; 0,5; 0,75; 1 и по физической модели выбирает вариант с
  максимальным min(КК, ИСС);
* `--refine N` — N итераций градиентной доводки после сети (по умолчанию 0 — чистая сеть);
  `--objective minmax` (по умолчанию) — доводка максимизирует худшую из двух метрик;
* `--method gs|adam` — классический Герчберг–Сэкстон или прямая оптимизация для сравнения;
* `--norm max|fit` — сохранение модуля: нормировка на максимум (по умолчанию) или масштаб МНК к исходному.

## Метод

### Физическая модель (`doe/physics.py`)

Поле в плоскости восстановления (слайд 2 задания):

K(x,y) = exp(jkz)/(jλz) · exp(jπ(x²+y²)/λz) · FFT[ H(u,v) · exp(jπ(u²+v²)/λz) ],

для фазового ДОЭ H = exp(jφ), и |K_i| = |FFT[exp(jφ)·Q_i]|, Q_i = exp(jπr²/λz_i).
Шаг сетки в плоскостях восстановления λz_i/(NΔu) = 10,0…11,5 мкм.

**Дискретизация.** Локальная частота чирпа Q_i у края ДОЭ равна (N/2)Δu²/(λz_i):
0,499; 0,475; 0,454; 0,434 цикла/пиксел для четырёх плоскостей, т. е. ниже предела
Найквиста 0,5. Безалиасная область чирп-функции λz/Δu² ≥ 128 пикселов при
z ≥ z_крит = NΔu²/λ = 24,06 мм. Минимальное расстояние задачи 24,1 мм выбрано ровно на
этой границе (см. `results/aliasing.png`), поэтому формула с одним БПФ корректна для всех
четырёх плоскостей.

**Дечирпирование.** Квадратичная фаза Q_i на краю ДОЭ достигает ~100 рад. Чтобы сеть не
воспроизводила эту быстро осциллирующую функцию, вводится опорная плоскость
1/z_ref = mean(1/z_i) (z_ref = 25,83 мм): φ = ψ − πr²/(λz_ref). В плоскостях остаются
только слабые относительные чирпы D_i = exp(jπr²/λ·(1/z_i − 1/z_ref)) (до ±13 рад в
углах). Переход φ ↔ ψ точный: тест `tests/test_core.py` сверяет его с прямой
формулой задания.

### Нейросеть (`doe/model.py`)

Физически информированная **развёрнутая (unrolled) сеть**. Модель Френеля встроена в
сеть как фиксированный дифференцируемый слой, а свёрточные U-Net работают только
в плоскостях изображений, где задача локальна:

```
цели A_1..A_4, α ─► U-Net ─► фазы θ_i в плоскостях изображений
ψ⁰ = arg Σ_i P_i⁻¹[A_i e^{jθ_i}]                          (обратное распространение)
повторить K раз (K = 4, у каждой стадии свой U-Net):
    F_i = P_i[e^{jψ}]                                      (прямое распространение)
    g_i = ∂L/∂|F_i|                                        (градиент потерь — «подсказка»)
    (w_i, m_i, δ_i) = U-Net_k(A_i, |F_i|, A_i − |F_i|, g_i, α)
    G_i = (A_i e^{w_i} + σ(m_i)|F_i|) · e^{j(arg F_i + δ_i)}
    ψ = arg Σ_i P_i⁻¹[G_i]
φ = wrap(ψ − πr²/(λ z_ref))  →  doe.png
```

Каждая стадия — обучаемый аналог итерации Герчберга–Сэкстона, дополненный градиентом
функции потерь по модулям полей. С этим входом сеть научилась режиму «тёмного фона»
для ИСС, которого базовый вариант не нашёл; score на контроле 0,722 против 0,672. сеть сама решает, как
перевзвесить целевые амплитуды (w), где оставить «свободу амплитуды» для отвода шума
(m, аналог MRAF) и как скорректировать фазу (δ). Все вычисления выполняются в одном
прямом проходе, без итераций во время работы.

### Обучение без учителя (`train.py`, `doe/losses.py`)

Готовые «правильные» ДОЭ не нужны: функция потерь сравнивает восстановление
|P_i[e^{jψ}]| с целями A_i через ту же модель Френеля:

L = (1 − α)(1 − КК) + α(1 − ИСС) + 0,1·СКО,  α ~ U[0, 1] для каждого примера.

ИСС в потерях считается для восстановления, нормированного на максимум, т. е. ровно
так, как изображение сохраняется в PNG. Это заметно повышает итоговый ИСС по сравнению
с масштабированием по МНК. Используются глубокий контроль промежуточных стадий
(вес 0,2), AdamW, косинусный спад шага обучения.

**Зачем α.** Плоскости разнесены всего на 1,2 мм, это сравнимо с глубиной фокуса
апертуры 1,28 мм (λ/NA² ≈ 0,8 мм). Поэтому в каждой плоскости неизбежно присутствует
расфокусированный свет трёх других изображений. Оптимум по КК Пирсона — равномерный
«засвеченный» фон (ИСС ≈ 0,1). Оптимум по ИСС — тёмный фон, но больше спекл-шума в
объекте. Это физический компромисс, а не недостаток метода (см. `results/tradeoff.png`),
поэтому он вынесен в управляющий вход сети.

### Данные (`doe/data.py`, `scripts/prepare_data.py`)

Банк изображений генерируется при запуске обучения. Четвёрки собираются случайно, с
отражениями и гамма-коррекцией.

| источник | доля | описание |
|---|---|---|
| процедурная синтетика | 35 % | символы (латиница, кириллица, цифры) разными шрифтами, фигуры, точки, решётки, 1/f-шум |
| SBS Noise Texture Pack 128×128 | 15 % | `data/textures`, 262 текстуры, CC0; 36 (номера 3 и 7 каждой категории) отложены для контроля |
| SBS Noise Texture Pack 512×512 | 30 % | фрагменты 128…512 px из полного пака [opengameart.org/content/700-noise-textures](https://opengameart.org/content/700-noise-textures) |
| CIFAR-10, оттенки серого | 20 % | как в [Jemuna/Image-Classification…](https://github.com/Jemuna/Image-Classification-Using-Deep-Learning-in-TensorFlow); 9000 обучающих / 1000 контрольных |

`examples/` содержит контрольные наборы, не участвующие в обучении: цифры, буквы, слова,
фигуры, фотографии (`skimage.data`) и три четвёрки отложенных текстур.


## Обучение

```bash
python scripts/prepare_data.py                 # текстуры 512 + CIFAR-10 → data/cache (опционально)
python train.py --out runs/main --hours 3 --grad-feat   # на GPU добавьте --amp --batch 24 --bank 80000
```

На Kaggle (GPU T4, нужен подтверждённый телефоном аккаунт):

```bash
python scripts/kaggle_run.py push --slug doe-nn-train --dataset fiskarik/doe-nn-data \
    --require-gpu --job "g4:--hours 3 --batch 24 --amp --bank 80000 --grad-feat"
python scripts/kaggle_run.py wait --slug doe-nn-train
python scripts/kaggle_run.py pull --slug doe-nn-train --dest runs/kaggle
```

## Метрики

* **КК** — коэффициент корреляции Пирсона (слайд 3).
* **ИСС (SSIM)** — индекс структурного сходства Wang et al. (2004) с гауссовым окном 11×11,
  σ = 1,5, L = 255. Совпадает со `skimage.metrics.structural_similarity(gaussian_weights=True,
  sigma=1.5, use_sample_covariance=False)` и MATLAB `ssim` (проверено в тестах).
* **ИСС 7×7** — SSIM как `skimage.metrics.structural_similarity` по умолчанию (равномерное
  окно 7×7) — для сопоставления с другими протоколами.
* **ИСС глоб.** — формула со слайда 3, где статистики берутся по всему кадру (одно окно).
  Тоже сохраняется в `metrics.csv`.

Все метрики считаются по сохранённым 8-битным PNG: ДОЭ квантуется в 256 уровней,
восстановление делается из квантованного ДОЭ.
